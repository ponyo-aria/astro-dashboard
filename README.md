# 遠征地判断ダッシュボード

天体撮影の遠征地を決めるための、スマホ（Android）向けのアプリです。
登録した撮影地ごとに、**「どの夜に、暗くて晴れた時間が何時間あるか」** を一覧で表示します。

- 公開URL：https://ponyo-aria.github.io/astro-dashboard/
- ブラウザで動くアプリ（PWA）です。サーバーは使わず、地点や予報はすべてスマホの中に保存します
- 圏外でも、最後に取得した予報で起動できます

---

## 1. はじめに（スマホのホーム画面に追加する）

1. スマホの Chrome で公開URLを開きます
2. 右上の「︙」を押し、「ホーム画面に追加」（または「アプリをインストール」）を押します
3. ホーム画面に月のアイコンが出ます。次からはこのアイコンから開きます
4. 初めて開いたとき「位置情報の使用を許可しますか？」と聞かれたら「許可」を押します（現在地の暗い時間を出すため）

新しい版が公開されたときは、アプリを開くと自動で新しい版に切り替わります（画面が1回読み込み直されます）。

---

## 2. 画面の見方

画面の下の4つのボタン（ホーム・詳細・比較・設定）で、画面を切り替えます。スマホの「戻る」操作で、1つ前の画面に戻ります（ホームの表から開いた詳細ならホームへ、比較から開いた詳細なら比較へ）。

### ホーム
- **上の1行**：取得した時刻、MSM（気象庁）の次の予報が出る時刻の目安、更新ボタン
  - 「MSM 新しい予報あり」と出たら、更新ボタンで新しい予報が取れます
  - 「MSM次回 まもなく」は、予報の公開が遅れている状態です
- **7夜のタブ**：日付・曜日（金＝黄、土＝青、日＝赤）・月の形・その夜いちばん良い判定。押すと下の表示が切り替わります
- **選んだ夜の要点**：暗い時間、月の出入り、月齢。「基準」で、暗い時間を計算する場所（現在地または登録地点）を選べます
- **全地点×時間の表**
  - 左：地点名と判定（例：◎ 5h ⚠）
  - 右：1時間ごとの雲（黒＝晴れ、白＝曇り。晴れのマスには水色の点）と、その時間の風速（m/s。黄＝5以上、赤＝8以上）
  - 上の帯：空の状態（紫＝暗い、黄＝月あり、灰＝薄明）
  - 表の上の「MSM｜ECMWF」で、雲をどちらのモデルで見るか切り替えられます
  - 行を押すと、その地点・その夜の詳細が開きます

### 詳細
- 下の「詳細」を押すと、最後に見ていた地点・夜の詳細が開きます（初めてのときは、ホームで選んでいる夜の、登録地点の1つ目）
- 上：「天気詳細」、地点名（押すと別の地点に切り替え）、「‹ 日付 ›」（前の夜・次の夜）、「今夜」
- 判定と、モデルごとの撮影可能時間、暗い時間・月・日没・天文薄明
- 1時間ごとの表：高層・中層・低層の雲、風速、月の高さ。表の上で MSM・ECMWF・GSM（参考）・AIFS（参考）を切り替えられます
- 最低気温、風、結露リスク、周辺5kmの低層雲、雲の流れ（上空の風向き。参考）、降水量（前日〜当日）
  - 風・結露・周辺5km低層雲のカードは、同じ見せ方で注意を知らせます：問題なし＝ふつう、**注意＝黄色の枠と背景**、**警戒＝赤の枠と背景**（数字も同じ色）
  - 風：平均の風速は MSM（届かない夜は ECMWF）、最大瞬間風速は ECMWF の 9km 版。平均 5m/s 以上か瞬間 10m/s 以上で注意、平均 8m/s 以上か瞬間 15m/s 以上で警戒。瞬間風速はモデルによって差が大きいので目安です
  - 結露：気温と露点の差（夜間でいちばん小さい値）。4℃以下で注意、2℃以下で警戒
  - 周辺5km低層雲：北・東・南・西それぞれの、暗い時間のうち一番多い時間の値。5% を超えたら注意、30% を超えたら警戒

### 比較
- 地点ごとに、7夜×4モデル（MSM・ECMWF・GSM・AIFS）の撮影可能時間を並べます。横棒は「暗い時間のうち晴れが続く割合」です
- 判定が割れた夜（△）は、行の左に黄色い線が付きます。参考モデル（GSM・AIFS）がどちら寄りかを見るのに使います
- 行を押すと詳細が開きます（モデルのマスを押すと、そのモデルの表示で開きます）

### 設定
- **表示**：赤色モード（ナイトモード）のスイッチ（オフ＝灰色で丸が左、オン＝赤で丸が右）。オンにすると画面全体が赤一色になります（撮影地で暗さに慣れた目を守るため）。天気予報は出発前に見ることが多いので、ホームには切り替えを置いていません
- **地点管理**：地点の追加・編集・削除・並べ替え、バックアップ（下の「5. バックアップ」）
  - 座標は「35.42, 138.58」の形か、Googleマップの長いURLを貼り付けます。短縮URL（maps.app.goo.gl）は読み取れません
  - 標高は座標から自動で取得します（手で直すこともできます）
- **リンク**：Windy（基準地点の場所で開く）・SCW・AstroBin を開きます
- **このアプリについて**：データの出どころ

## 3. 判定の決まり

| 言葉 | 意味 |
| --- | --- |
| 夜 | その日の日没から、翌日の日の出まで |
| 暗い時間 | 太陽の高さが −18° 以下（天文薄明が終わってから始まるまで）で、しかも月が沈んでいる時間 |
| 晴れ | 低層・中層・高層の雲量が**すべて 5% 以下**の時間（薄雲も不可） |
| 撮影可能時間 | 暗い時間のうち、晴れが**続いている**いちばん長い時間 |
| 撮影可 | 撮影可能時間が **3時間以上** |

| 記号 | 意味 |
| --- | --- |
| ◎ 可 | MSM と ECMWF の両方が「撮影可」（1〜4夜目） |
| △ 割れ | MSM と ECMWF で判定が分かれた（「△ 5h/0h」は MSM 5時間・ECMWF 0時間） |
| × 不可 | 両方が「撮影不可」 |
| ○ 参考：可 ／ 参考 × | 5〜7夜目。MSM が届かないので ECMWF だけで判断した目安 |
| 月明かり | 暗い時間がそもそも3時間に満たない夜 |
| ⚠ | 周辺5km（北・東・南・西）のどこかで、暗い時間に低層雲が 30% を超える。判定そのものは変えない警告 |

- 判定（◎△×）に使うのは **MSM と ECMWF だけ**です。GSM と AIFS は見比べるための「参考モデル」です
- ⚠ は、MSM が届く夜は MSM（約5km四方）、届かない夜は ECMWF の周辺4点で判断します

### 使っている予報モデル

| モデル | 作っているところ | 細かさ | 何日先まで | 用途 |
| --- | --- | --- | --- | --- |
| MSM | 気象庁 | 約5km四方 | 約4日 | 判定 |
| ECMWF（IFS） | 欧州中期予報センター | 約25km四方 | 7夜ぶん | 判定 |
| GSM | 気象庁（全球） | 約55km四方 | 7夜ぶん | 参考 |
| AIFS | ECMWF（AI版） | 約28km四方 | 7夜ぶん | 参考（元は6時間ごとの値を1時間ごとに補間） |

## 4. しきい値（判定の数字）の変え方

判定に使う数字は、すべて [src/config.js](src/config.js) の1か所にまとめてあります。

| 項目名 | 今の値 | 意味 |
| --- | --- | --- |
| `cloudCoverClearMax` | 5 | 「晴れ」とみなす雲量の上限（%）。3層すべてがこれ以下なら晴れ |
| `minClearHours` | 3 | 「撮影可」とみなす撮影可能時間（時間） |
| `lowCloudRiskThreshold` | 30 | ⚠ を出す周辺点の低層雲量（%）。詳細画面の「周辺5km低層雲」はこれを超えたら警戒（赤） |
| `surroundingLowCloudCautionThreshold` | 5 | 詳細画面の「周辺5km低層雲」で、これを超えたら注意（黄） |
| `surroundingPointDistanceKm` | 5 | 周辺点を置く距離（km） |
| `dewPointRiskHighMax` | 2 | 気温と露点の差（℃）がこれ以下なら結露リスク「警戒」（赤） |
| `dewPointRiskCautionMax` | 4 | 気温と露点の差（℃）がこれ以下なら結露リスク「注意」（黄） |
| `windCautionThreshold` | 5 | 平均の風速（m/s）がこれ以上で「注意」（黄）。表のマスの風速の数字も同じ |
| `windDangerThreshold` | 8 | 平均の風速（m/s）がこれ以上で「警戒」（赤） |
| `gustCautionThreshold` | 10 | 最大瞬間風速（m/s）がこれ以上で「注意」（黄） |
| `gustDangerThreshold` | 15 | 最大瞬間風速（m/s）がこれ以上で「警戒」（赤） |
| `matrixPaddingHours` | 1 | ホームと詳細の表で、天文薄明の前後に足して表示する時間。大きくすると日没〜日の出まで見える |

**変える手順**
1. [src/config.js](src/config.js) の数字を書き換えて保存します
2. ターミナルで `npm test` を実行し、テストが通るか確かめます（数字によっては、テストの直しが必要なことがあります）
3. `npm run deploy` で公開します
4. スマホでアプリを開くと、新しい数字で判定されます

## 5. 地点データのバックアップ

地点はスマホの中（このアプリの保存場所）だけにあります。機種変更やブラウザのデータ消去に備えて、ときどきバックアップしてください。

**書き出す（バックアップ）**
1. 下の「設定」を押し、地点の一覧の下にある「バックアップ（書き出し・読み込み）」を押します
2. 「バックアップ」の「JSONを書き出す」を押します
3. スマホに地点のファイル（.json）が保存されます。Google ドライブなどにも残しておくと安心です

**読み込む（元に戻す）**
1. 下の「設定」を押し、地点の一覧の下にある「バックアップ（書き出し・読み込み）」を押します
2. 「置き換え」（今の地点を消して読み込んだ地点にする）か「追加」（今の地点に足す）を選びます
3. 「ファイルを選択」で、書き出したファイルを選びます

注意：Chrome の「サイトのデータを削除」を行うと、地点・保存済みの予報・現在地・設定がすべて消えます。

## 6. 開発する人向け

### よく使うコマンド
| コマンド | すること |
| --- | --- |
| `npm install` | 必要な道具を入れる（最初の1回） |
| `npm run dev` | Mac で開発用の画面を開く（表示されたURLをブラウザで開く） |
| `npm test` | 自動テストを実行する |
| `npm run build` | 公開用のファイルを `dist` に作る |
| `npm run deploy` | 公開用のファイルを作って GitHub Pages に公開する |
| `npm run icons` | `public/icon.svg` からアプリのアイコン（各サイズ）を作り直す |

### フォルダの中身
| 場所 | 中身 |
| --- | --- |
| `src/screens/` | 各画面（ホーム・詳細・比較・地点・リンク）と、画面で共通に使う部品 |
| `src/logic/` | 判定・天文計算・表の計算など（画面から切り離して、テストできるようにしてある） |
| `src/api/` | 予報・標高・現在地の取得 |
| `src/storage/` | スマホへの保存（地点・予報） |
| `src/serviceWorker/` | 圏外でも起動できるようにする仕組み（アプリ本体をスマホに保存する） |
| `src/config.js` | 判定のしきい値 |
| `tests/` | 自動テスト |
| `docs/` | 仕様書と進捗の記録 |

### 守っていること
- APIキーやパスワードなどの秘密の情報はコミットしない（このアプリは秘密の情報を使っていません）
- 地点の座標などの個人の情報は、リポジトリやドキュメントに書かない（地点はスマホの中にだけ保存）
- 現在地は、暗い時間などの計算にだけ使い、どこにも送らない

## 7. データの出典・ライセンス

- 気象データ：[Open-Meteo.com](https://open-meteo.com/)（[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/deed.ja)）。気象庁・ECMWF などの公開データを、Open-Meteo を通して使っています。アプリでは、判定のために加工して表示しています

- 天文計算：[Astronomy Engine](https://github.com/cosinekitty/astronomy)（MIT License）
- グラフ：[Chart.js](https://www.chartjs.org/)・[chartjs-plugin-annotation](https://github.com/chartjs/chartjs-plugin-annotation)（どちらも MIT License）
- 判定はこのアプリ独自の目安で、各機関の予報そのものではありません
