- オーナーの要望：風・結露の注意の見せ方が違う（風は黄色の文字、結露は「高」の札）ので統一し、風や低層雲も白→黄→赤の段階にしたい
  - 段階の決め方を`src/logic/levels.js`に集約（'ok'／'caution'／'danger'）
  - 詳細画面の小さなカード：注意＝黄色の枠とうすい黄色の背景、警戒＝赤の枠とうすい赤の背景、右上の枠の上に「注意」「警戒」の札。数字も同じ色
  - 結露：「高」の札をやめ、気温と露点の差（例：0.2℃）を大きな数字で出す。4℃以下で注意、2℃以下で警戒（しきい値は今までどおり）
  - 風：平均と瞬間それぞれで段階を決め、厳しい方をカードの段階に。オーナー判断で警戒は平均8m/s以上・瞬間15m/s以上（`windDangerThreshold`・`gustDangerThreshold`）
  - 周辺5km低層雲：方角ごとに数字の色を付け、いちばん厳しい方角をカードの段階に
  - ホーム・詳細の表のマスの風速の数字も、同じ白→黄→赤（凡例も「黄＝5・赤＝8以上」に）

## 改善：詳細画面のカードの並びと「直前の雨」（2026-11-05）

- オーナーの指示：カードの順番を「風・周辺5km低層雲・雲の流れ／最低気温・降水量・結露リスク」に（1段目＝風と雲、2段目＝温度と水分）→ 対応
- オーナーの要望：降水量は「前日〜当日の合計」では意味が薄い。晴れる直前の雨など、地面の湿りや霧・靄の発生リスクを判断する材料にしたい。最適な表示方法を検討して
  - 検討：大事なのは「暗くなる前に、どれだけ降って、いつ止んだか」。前日〜当日の合計は、きのうの朝の雨まで含み、夜間の雨は含まず、いつ止んだかも分からなかった
  - 作ったもの：「直前の雨」のカード（`recentRain`）。大きな数字＝暗くなる時刻（天文薄明の終わり）までの24時間の雨の量（無ければ「なし」）、補足＝止んでからの時間（「止んで4時間」「止んだばかり」「暗くなる時も雨」「24時間降雨なし」）、夜間にも降る予報なら「夜間も ○mm」
  - 段階（`rainLevel`）：暗くなる前12時間に1mm以上、または24時間で10mm以上で注意（黄）。暗くなる時も雨、または夜間に0.5mm以上の予報で警戒（赤）。しきい値は`src/config.js`の`rainLookbackHours`・`rainRecentHours`・`rainWetMinMm`・`rainHeavyMm`・`rainNightMinMm`
  - 実データで確かめたときに、前日の大雨（例：八ヶ岳 26.9mm、止んで11時間）に色が付かなかったため、「24時間で10mm以上」の決まりを追加。夜間の少しの雨（警戒の量に届かない）で補足が赤くなっていたのも直した
  - 霧や靄の出やすさは「気温と露点の差」が小さいほど高いので、隣の結露リスクと並べて見る形にした
  - Open-Meteo の雨の量は「その時刻までの1時間に降った量」として計算
